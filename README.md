# Портфолио Леонида Кривошеина

Статичный сайт на двух языках: русская версия в корне (`index.html`), английская в `en/`.
Без фреймворков и сборщиков, работает на GitHub Pages как есть.

## Как поменять текст или цифры

1. Откройте `build.py`.
2. Цифры лежат в блоке `DATA` в начале файла. Производные показатели (стоимость пациента, CTR и т. п.) считаются автоматически.
3. Тексты лежат в функции `texts()`: русская и английская версия стоят рядом, через `if ru else`.
4. Запустите `python3 build.py`: он заново соберёт `index.html` и `en/index.html`.

Мелкую правку можно сделать и прямо в `index.html`, но при следующей сборке она перезапишется.

## Публикация на GitHub Pages

1. Залейте содержимое папки в репозиторий (например, `portfolio`).
2. Settings → Pages → Source: Deploy from a branch → `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://<ник>.github.io/portfolio/`.
4. Впишите этот адрес в `SITE_URL` в `build.py` и пересоберите: так появятся превью ссылки для LinkedIn и Telegram (`assets/og-ru.png`, `assets/og-en.png`).

## Что где

- `assets/style.css` — оформление
- `assets/app.js` — фильтр каналов, таблицы, подсказки на графиках
- `assets/fonts/` — шрифт Geologica (лицензия SIL Open Font License)
- `assets/leonid.jpg` — фото
